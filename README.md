# Shinjuku Showdown: Flappy Battle

Static HTML/CSS/JavaScript Canvas game. No build command or server backend required.

## Publish with GitHub Pages

Upload this folder's contents (not the ZIP itself) to the root of a new repository. With GitHub Free use a public repository. In Settings > Pages, choose Deploy from a branch, main, / (root), then Save. Use the published URL reported by GitHub after deployment; do not treat a guessed URL as verified.

Keep index.html at the repository root and preserve the assets subfolders. Relative asset paths support project sites under /repository-name/.

## Controls

Choose Gojo or Yuji and Practice or Challenge. Space / canvas click flies; J uses the active skill; K uses the ultimate at 100 energy. Music begins after Start Battle and has independent toggle/volume controls. Records are browser-local. Combat character drawings remain labeled development art; approved background portraits are used for selection and results.

Future updates to main trigger republication. Test actual access and playback after deployment; accessibility from every network is not guaranteed.
